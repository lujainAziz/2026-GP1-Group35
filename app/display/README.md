# Assas on-device display

The Assas on-device display: the Flutter application for the 7-inch screen on the Raspberry Pi,
which runs there as a fullscreen Linux application.

## Run

From the repository root:
```bash
cd app/display
flutter pub get
flutter run -d linux
```

For build instructions, platform configuration, demo mode and Raspberry Pi kiosk setup, see
[app/SETUP.md](../SETUP.md).
